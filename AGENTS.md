A starter kit for giving your projects an agent system. Clone it, point your agent at this file, and say **go**.

If told to go, start, or begin: read `agents/orchestrator.md` and follow its instructions.

## Key Files

- `agents/` — Role files (orchestrator, auditor, builder, librarian)
- `patterns/` — 11 reusable agent system patterns with templates
- `audits/current.md` — Latest cross-project gap analysis
- `skills/coding-discipline/` — Code quality defaults for builder agents
